# LMS WahBaby

On the Last Man Standing worlds, other players' public chat in LMS games and in Ferox Enclave
is shown as "Wah" (or "*cries*", "*throws controller*"...), unless the message is just
"gl", "gf", "gg", "good luck", "good fight" or "good game". Typos, repeats and extras like
"gl hf", "glglgl", "GGGGG" or "gf all" are allowed too.

Only your own client is affected: nothing is sent to the game, and other players still see
what was actually typed. Your own messages are never changed.

## Settings

- **In LMS games / In Ferox Enclave**: where it's active.
- **Casual LMS worlds too**: by default only the members "LMS Competitive" worlds count.
- **Replace overhead text**: also change the text above players' heads.
- **Allowed phrases**: messages to leave alone (comma-separated).
- **Replacements**: what to show instead (comma-separated, picked at random).
